== 样本书

* xref:books/00-book-anatomy/book.adoc[00 完整书籍结构标本]：覆盖 book 的前置、正文、分部和后置结构。
* xref:books/01-starter-book/book.adoc[01 日常独立单书]：新增普通 book 的复制起点。
* xref:books/02-multipart-monograph/book.adoc[02 长书分部]：同一本 book 内部的 part 结构。
* xref:books/03-technical-book-workflow/book.adoc[03 技术书工作流]：图表、代码片段和资源边界。
* xref:books/04-reference-manual/book.adoc[04 参考手册]：结构选择、路径规则和引用模式。
* xref:books/05-upper-volume/book.adoc[05 上册]：独立分卷的上册。
* xref:books/06-lower-volume/book.adoc[06 下册]：独立分卷的下册，并引用上册。

== 项目设计书

* xref:books/08-rdf12-heading-projection-query-workflow/book.adoc[08 AsciiDoc 书稿 RDF 投影查询工作流]：定义书稿 RDF 投影查询工作流、查询语句集和写作回源闭环。
* xref:books/10-inkrail-cli-design/book.adoc[10 inkrail CLI 设计书]：定义 inkrail 的对象边界、项目记忆、投影新鲜度和查询契约。
* xref:books/11-inkrail-software-architecture-and-quality-design/book.adoc[11 inkrail 软件架构与工程质量设计书]：定义 inkrail runtime 的公共库 API、模块结构、运行流、适配器和工程质量基线。
* xref:books/12-inkrail-runtime-implementation-wbs/book.adoc[12 inkrail Runtime 实现工作分解与治理计划书]：定义 inkrail runtime 实现的工作包、审核包、状态台账和关闭条件。

== 书籍边界速判

* 只是同一本书内部的第一部、第二部：看 xref:books/02-multipart-monograph/book.adoc[02 长书分部]。
* 上册和下册需要独立入口、独立构建和跨卷引用：看 xref:books/05-upper-volume/book.adoc[05 上册] 与 xref:books/06-lower-volume/book.adoc[06 下册]。
* 新增一本普通书：从 xref:books/01-starter-book/book.adoc[01 日常独立单书] 开始。
* 查路径、引用和增长规则：看 xref:books/04-reference-manual/book.adoc[04 参考手册]。
