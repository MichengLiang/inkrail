[#error-semantics]
== 错误语义

错误码是恢复动作的索引。`inkrail` 使用稳定错误码区分配置、书架、book entry、投影、加载和查询失败。

[cols="1,3,3", options="header"]
|===
|错误码 |含义 |恢复动作

|`BOOK_REQUIRED`
|项目无法解析唯一目标书。
|传入 `--book` 或设置 `project.default_book`。

|`BOOK_NOT_FOUND`
|指定 book 未登记或标准书架中不存在对应 `book.adoc`。
|检查 `[[books]]` 或书架 `books/<book-id>/book.adoc`。

|`BOOK_CONFIG_INVALID`
|book 配置路径、profile 或字段不合法。
|修正 `.inkrail/config.toml`。

|`WORKSPACE_NOT_FOUND`
|书架根目录不存在。
|检查 `bookshelves.root`。

|`BOOKSHELF_INIT_TARGET_INVALID`
|书架初始化目标路径存在且不是目录。
|选择不存在路径或空目录作为目标书架目录。

|`BOOKSHELF_INIT_TARGET_NOT_EMPTY`
|书架初始化目标目录非空且未传 `--force`。
|选择空目录，或传入 `--force`。

|`BOOKSHELF_NOT_FOUND`
|指定书架未登记。
|检查 `[[bookshelves]]` 或传入已登记书架 id。

|`BOOKSHELF_PROFILE_UNSUPPORTED`
|书架本地构建调度收到非标准 profile。
|使用标准 profile 书架，或直接在目标书架内运行自有构建命令。

|`BOOKSHELF_SCRIPT_NOT_FOUND`
|标准书架缺少本地 `build`、`check` 或 `clean` package script。
|检查书架 `package.json`。

|`BOOKSHELF_RUNTIME_NOT_FOUND`
|标准书架缺少 `tools/adoc-books.mjs`。
|检查标准书架初始化结果。

|`BOOKSHELF_BUILD_FAILED`
|标准书架本地 `build`、`check` 或 `clean` 动作执行失败。
|阅读书架本地运行时输出并修复书架源文件或构建环境。

|`BOOK_ENTRY_NOT_FOUND`
|书本入口不存在。
|创建或修正 `books/<book-id>/book.adoc`。

|`SOURCE_SET_FAILED`
|book-entry source set 无法构造。
|检查 include target、include attrlist、documentRoot 和 include path 边界。

|`PROJECTION_FAILED`
|book entry 到 RDF 投影失败。
|检查 book entry、投影器版本和 projection options。

|`TTL_READ_FAILED`
|TTL 文件无法读取。
|检查文件权限和路径。

|`TTL_LOAD_FAILED`
|Oxigraph 无法加载 TTL。
|重新投影或检查 Turtle 语法。

|`QUERY_READ_FAILED`
|查询文本无法读取。
|检查 `--file`、stdin 或命令参数。

|`QUERY_FAILED`
|SPARQL 执行失败。
|修正查询语句或查询能力假设。

|`STALE_PROJECTION`
|项目模式检测到过期投影且无法刷新。
|修复 source set 或投影失败原因；不能使用 stale TTL 继续查询。

|`TOOL_NOT_FOUND`
|外部命令缺失。
|安装依赖或修正配置命令。
|===

成功 JSON 写 stdout。失败 JSON 写 stderr。pretty 模式失败时，stderr 输出错误码、错误消息和必要 details，不输出 stack trace。
