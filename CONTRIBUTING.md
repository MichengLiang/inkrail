# Contributing to inkrail

inkrail is maintained by its core team as a source-available product project.
Public source access supports review, reproducibility, issue reporting, and
noncommercial use. Public source access does not make the project
community-governed.

## Contribution Boundary

Issues, reproducible bug reports, documentation corrections, and design
questions are welcome.

Do not prepare unsolicited feature implementations. Open an issue first and
wait for maintainer direction before writing a substantive pull request.
Maintainers may close unsolicited implementation pull requests without review.

Substantive external contributions require prior maintainer approval and a
signed Contributor License Agreement before merge. Maintainers decide whether a
contribution is trivial. Documentation, specifications, examples, tests,
configuration, build scripts, and implementation code are substantive unless
maintainers explicitly classify the change as trivial.

## Contributor License Agreement

The project Contributor License Agreement is available in [CLA.md](CLA.md).

A contribution can be merged only when the required CLA status is satisfied.
Signing the CLA does not require maintainers to accept, review, publish, or
maintain a contribution.

Maintainers must confirm and record CLA acceptance before merging a substantive
external contribution. Pull request checklist items are reminders; they are not
the CLA signature or acceptance record.

## Contribution Authority

Contributors must have the right to submit their contributions. If a
contribution is made on behalf of an employer, client, school, or other
organization, the contributor must have authority to grant the project the
rights described in [CLA.md](CLA.md). Maintainers may require separate written
authorization or an organization contributor agreement before accepting the
contribution.

## Commercial Use

inkrail is licensed for noncommercial use under the PolyForm Noncommercial
License 1.0.0. Commercial use requires a separate license from the copyright
holder. See [COMMERCIAL.md](COMMERCIAL.md).

This commercial-use policy applies to inkrail. It does not change the licenses
of separate projects such as `asciidoc-abundant-tree` or
`create-asciidoc-multi-book-workspace`.
