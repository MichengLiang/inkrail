# inkrail

`inkrail` is currently a specification package for a planned CLI that manages project memory, projection freshness, and SPARQL query workflows for AsciiDoc multi-book workspaces.

The current package reserves the public npm name and points to the design book. It does not yet export a runtime CLI, parser, projection engine, query library, or SDK.

## Documentation

- Design book: <https://michengliang.github.io/inkrail/>
- Source repository: <https://github.com/MichengLiang/inkrail>
